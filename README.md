# DiagramFlow

DiagramFlowは、ノードと接続（コネクション）を使用してフロー図を作成、編集、管理できるWPFベースの図形編集アプリケーションです。

## 機能

- **ノード管理**: ノードの作成、移動、サイズ変更、削除。
- **接続管理**: ノード間を線で結び、フローを表現します。
- **図形**: 複数のノード形状をサポートしています：
  - 長方形 (Rectangle)
  - 楕円 (Ellipse)
  - ひし形 (Diamond)
- **編集ツール**:
  - **元に戻す/やり直し**: すべての操作に対する完全な履歴スタックをサポート。
  - **クリップボード**: ノードと接続のコピー＆ペースト（JSON形式）。
  - **選択機能**: ラバーバンド（矩形）選択およびCtrlキーを使用した複数選択。
  - **ズームとパン**: キャンバスのスムーズな拡大縮小と移動。
- **保存機能**: JSONファイルへの図の保存と読み込み。

## 技術スタック

- **フレームワーク**: .NET Framework 4.7.2
- **UI**: WPF (Windows Presentation Foundation)
- **アーキテクチャ**: MVVM (Model-View-ViewModel)
- **ライブラリ**:
  - `Microsoft.Xaml.Behaviors.Wpf`: インタラクションビヘイビア用
  - `Newtonsoft.Json`: シリアル化（保存/読み込み）用
  - `PropertyChanged.Fody`: INotifyPropertyChanged実装の簡略化用
  - `ReactiveProperty`: リアクティブプログラミング用（使用時）

## はじめに

1. リポジトリをクローンします。
2. Visual Studioで `DiagramFlow.sln` を開きます。
3. ソリューションをビルドしてNuGetパッケージを復元します。
4. `DiagramFlow` プロジェクトを実行します。

## 使い方

- **ノードの追加**: ツールバーの図形ボタン（Rectangle, Ellipse, Diamond）をクリックしてキャンバスに追加します。
- **接続**: ノードを選択またはホバーすると表示されるポート（接続点）から、別のノードのポートへドラッグして接続線を作成します。
- **選択**: クリックしてノードを選択します。キャンバス上でドラッグすると範囲選択（ラバーバンド選択）ができます。Ctrl+クリックで選択の切り替え（追加/解除）ができます。
- **移動**: 選択したノードをドラッグして移動します。
- **サイズ変更**: ノードを選択すると右下に表示される白いハンドルをドラッグしてサイズを変更します。
- **テキスト編集**: ノードをダブルクリックするとテキスト編集モードになります。
  - `Enter`: 確定して終了
  - `Esc`: キャンセルして元のテキストに戻す
- **ズーム（拡大・縮小）**:
  - `Ctrl`キーを押しながらマウスホイールを回転させます。
  - キャンバス上の何もない場所を左ダブルクリックすると、拡大率が100%と200%で切り替わります。
- **パン（視点移動）**: キャンバス上の何もない場所で右クリックしたままドラッグして視点を移動します。
- **ショートカット**:
  - `Ctrl + Z`: 元に戻す (Undo)
  - `Ctrl + Y`: やり直し (Redo)
  - `Ctrl + C`: コピー
  - `Ctrl + V`: 貼り付け
  - `Delete`: 選択したアイテム（ノードまたは接続）の削除
