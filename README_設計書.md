# DiagramFlow 設計書PowerPoint について

## 概要

このリポジトリには、DiagramFlowプロジェクトの包括的な設計書がPowerPoint形式で含まれています。

**ファイル名**: `設計書.pptx`

## 内容

設計書PowerPointには、以下の21スライドが含まれています：

1. **タイトルスライド** - DiagramFlow設計書
2. **プロジェクト概要** - アプリケーションの目的と主な特徴
3. **技術スタック** - 使用フレームワーク、ライブラリ
4. **システムアーキテクチャ** - MVVMパターンとディレクトリ構造
5. **図形仕様** - サポートされる図形と操作方法
6. **接続線仕様** - 接続機能の詳細
7. **選択機能** - 単一選択と複数選択の仕様
8. **ズーム・パン機能** - キャンバス操作の詳細
9. **テキスト編集機能** - インライン編集の仕様
10. **Undo/Redo機能** - 履歴管理システム
11. **クリップボード機能** - コピー＆ペースト
12. **ファイル操作** - JSON保存・読み込み
13. **データモデル** - DTO定義
14. **操作状態管理** - 状態遷移モデル
15. **UI構成** - メイン画面のレイアウト
16. **実装計画フェーズ** - 段階的開発計画
17. **テスト方針** - テスト戦略
18. **非機能要件** - 操作性、拡張性、保守性
19. **制約事項と設計原則** - 技術的制約とMVVM原則
20. **将来拡張の可能性** - 検討中の機能
21. **まとめ** - 設計の要約

## 作成方法

この設計書は、以下のドキュメントを基に作成されました：

- `DiagramFlow/Documents/RequirementsDefinition.md` - 要件定義書
- `DiagramFlow/Documents/ImplementationPlan.md` - 実装計画書
- `DiagramFlow/Documents/DiagramEditorSpecification.md` - 仕様書（最終版）
- `README.md` - プロジェクト概要

Python-pptxライブラリを使用して、これらのMarkdownドキュメントの内容を構造化されたPowerPointプレゼンテーションに変換しました。

## 使用方法

1. `設計書.pptx` ファイルをMicrosoft PowerPoint、LibreOffice Impress、またはその他の互換性のあるプレゼンテーションソフトウェアで開きます。
2. プロジェクトの全体像を把握するために、スライドを順番に確認します。
3. チームメンバーや関係者とのミーティングで使用します。
4. 実装時の参照資料として活用します。
