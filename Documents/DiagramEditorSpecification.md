# ダイアグラムエディタ仕様書（最終版）

## 0. 概要

本仕様書は、WPF（.NET Framework 4.7.2 / C# 7.3）を用いて実装する
**ダイアグラム編集アプリケーション**の最終仕様を定義する。

本アプリケーションは、ScrollViewer 内の Canvas 上に図形を配置し、
ズーム・パン・選択・接続線編集・Undo/Redo・JSON 保存を行うことを目的とする。

---

## 2. 図形仕様

### 2.1 図形の種類

* 対応図形：**矩形のみ**
* テキスト表示：図形内に表示可能
* 楕円・菱形：非対応（将来拡張）

---

### 2.2 図形の操作範囲

| 操作    | 対応           |
| ----- | ------------ |
| 移動    | 対応（確定）       |
| サイズ変更 | 対応（リサイズハンドル） |
| 回転    | 非対応（将来対応）    |

* **最小サイズ制限**：30x30 pixel
* これ以下へのリサイズ操作は無視、または制限される

### 2.4 図形の追加

* **ツールバー（画面上部）** の矩形アイコンをキャンバスへドラッグ＆ドロップして追加

### 2.5 テキスト編集

* **図形上のダブルクリック** でテキスト編集モードへ移行（TextBoxを表示）
* 編集確定：Enter またはフォーカス外クリック
* キャンセル：Esc

---

## 3. 選択仕様

### 3.1 単一選択

* 左クリックで図形を選択
* 他図形の選択は解除

### 3.2 複数選択

* Ctrl + 左クリックで追加選択
* ドラッグによる範囲選択（矩形ラバーバンド）対応

### 3.3 削除操作

* `Delete` キー：選択中の図形・接続線を削除

---

## 4. 接続線（エッジ）仕様

### 4.1 基本仕様

* 図形同士を直線で接続
* 接続点（ポート）の概念あり
  * **ポート位置**：各図形の上下左右の4辺中央に固定
* 図形移動時、接続線は追従
* **制約**：自己ループ接続許可、多重接続許可

### 4.2 作成操作

* 図形の縁にある **接続点（ポート）からドラッグ** して別の図形のポートへドロップして作成

---

## 5. キャンバス操作仕様

### 5.1 ズーム

* Ctrl + MouseWheel でズームイン／アウト
* ズーム中心：マウスカーソル位置
* Slider によるズーム率操作（双方向同期）
* ズーム範囲：10% ～ 400%

### 5.2 パン（移動）

* **右クリックドラッグ**でパン操作（操作中はカーソルを Hand に変更）
* ScrollViewer + ScaleTransform を使用
* RenderTransform は使用せず、**LayoutTransform** を使用する（スクロールバー連動のため）

### 5.3 ダブルクリック操作

* **空白領域のダブルクリック** で以下をトグル

  * クリック位置中心ズーム
  * 全体表示
* 図形上のダブルクリックはテキスト編集優先（2.5参照）
* ズームはアニメーションで段階的に実施（200～300ms）

### 5.4 コンテキストメニュー

* **右クリック（クリックのみ）**：コンテキストメニュー表示
* 右ドラッグ（パン操作）とは区別して判定する

### 5.5 キャンバス設定

* サイズ：固定（10000 x 10000 pixel）
* 自動拡張：なし

---

## 6. 操作状態遷移仕様（最重要）

### 6.1 操作状態一覧

| 状態           | 説明        |
| ------------ | --------- |
| Idle         | 何も操作していない |
| Selecting    | 選択操作中     |
| DraggingNode | 図形移動中     |
| ResizingNode | サイズ変更中    |
| Panning      | キャンバス移動中  |
| Connecting   | 接続線作成中    |

### 6.2 排他制御ルール

* 同時に複数の操作状態にはならない
### 6.3 クリップボード操作

* `Ctrl+C`：選択中の図形をコピー
* `Ctrl+V`：キャンバス中央（またはマウス位置）にペースト

### 6.4 補助機能（非対応）

* グリッド表示：なし
* スナップ吸着：なし

---

## 7. Undo / Redo 仕様

* ショートカット：Undo `Ctrl+Z`, Redo `Ctrl+Y`

### 7.1 対象操作

| 操作    | Undo 対象 |
| ----- | ------- |
| 図形追加  | ○       |
| 図形削除  | ○       |
| 図形移動  | ○       |
| サイズ変更 | ○       |
| 接続線操作 | ○       |
| 選択変更  | ×（UX優先） |

### 7.2 履歴粒度

* 図形移動：ドラッグ開始～終了で 1 履歴
* 履歴最大保持数：100

### 7.3 設計方針

* Command パターン採用
* Undo/Redo は状態差分のみ保持
* JSON 永続化とは完全分離

---

## 8. JSON 保存仕様

### 8.1 保存対象

* 図形一覧
* 図形属性（位置・サイズ・テキスト）
* 接続線
* ズーム率（任意）

※ Undo / Redo 履歴は保存しない

### 8.3 ファイル操作UI

* **ツールバー（画面上部）** に以下のボタンを配置
  * 保存（Save）：現在のキャンバス状態をJSONへ保存
  * 開く（Open）：JSONファイルを読み込みキャンバスを復元
  * 新規作成（New）：キャンバスをクリア（確認ダイアログ表示）

---

## 9. Command と Serializer の責務分離

### 9.1 基本原則

* Undo / Redo：操作履歴の再現のみ
* JSON 保存：現在状態のスナップショット
* 相互依存禁止

### 9.2 Command の責務

* ViewModel 状態変更
* Execute / Undo を提供
* JSON 非依存

### 9.3 Serializer の責務

* ViewModel ⇔ DTO 変換
* Command を生成しない
* Undo 履歴を操作しない

---

## 10. UI / アーキテクチャ

### 10.1 MVVM 方針

* View：表示と入力のみ
* ViewModel：状態・Command
* Model/DTO：純データ

### 10.2 禁止事項

* View から直接 Model 操作
* Serializer 内で Command 実行
* Undo 処理で JSON 再生成
