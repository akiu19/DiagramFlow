# 要件定義書

## 1. 概要

本アプリケーションは、WPF（.NET Framework 4.7.2 / C# 7.3）を用いて、スクロール可能なキャンバス上に図形を配置し、ダイアグラム図を作成・閲覧・操作できるデスクトップアプリケーションである。

本要件定義では、特に**キャンバス操作（ズーム・パン）**に関するユーザー操作およびUI連動を中心に定義する。

---

## 2. 対象環境

| 項目      | 内容                   |
| ------- | -------------------- |
| OS      | Windows 10 / 11      |
| フレームワーク | .NET Framework 4.7.2 |
| 言語      | C# 7.3               |
| UI技術    | WPF                  |
| 入力デバイス  | マウス、キーボード            |

---

## 3. 用語定義

| 用語     | 説明                        |
| ------ | ------------------------- |
| キャンバス  | 図形を配置する作業領域（WPF Canvas）   |
| ビューポート | ScrollViewerで表示されている可視領域  |
| ズーム率   | キャンバス全体に対する拡大縮小倍率（例：100%） |
| パン     | 表示領域をドラッグ操作で移動すること        |

---

## 4. 機能要件

※本章には、キャンバス操作機能に加え、図形操作および編集履歴管理（Undo / Redo）を含む。

### 4.1 レイアウト構成

* 画面は以下の構成を基本とする

  * ScrollViewer

    * 内部に Canvas を配置
  * ScrollViewer 外にズーム操作用 Slider を配置

---

### 4.2 ズーム機能（Ctrl + MouseWheel）

#### 概要

* Ctrlキーを押下したままマウスホイールを回転させることで、キャンバスをズームイン／ズームアウトできる

#### 操作仕様

| 操作           | 動作     |
| ------------ | ------ |
| Ctrl + ホイール上 | ズームイン  |
| Ctrl + ホイール下 | ズームアウト |

#### 詳細仕様

* ズームの中心点は**マウスカーソル位置**とする
* ズーム率は内部的に `ScaleTransform` で管理する
* ズーム率は最小値・最大値を持つ

  * 最小：例 10%（0.1）
  * 最大：例 400%（4.0）
* ズーム操作時、ScrollViewerのスクロール位置は、ズーム前後でマウス位置が同一論理座標を指すよう補正される

---

### 4.3 キャンバス移動（パン操作）

#### 概要

* 右クリックを押下したままドラッグすることで、キャンバス内の表示位置を移動できる

#### 操作仕様

| 操作           | 動作          |
| ------------ | ----------- |
| 右クリック + ドラッグ | 表示領域の移動（パン） |

#### 詳細仕様

* パン操作は**常に右クリックドラッグ**で行う
* 左クリック操作は、図形の選択・移動・範囲選択専用とする
* マウスダウン時の座標と、ドラッグ中の差分から ScrollViewer の HorizontalOffset / VerticalOffset を更新する
* パン操作中はマウスカーソルを「移動中」表示（Hand 等）に変更する
* パン操作中は、図形の選択・移動処理を無効化する

---

### 4.4 ダブルクリック操作

#### 概要

* キャンバス上のダブルクリック操作により、ズーム操作を実行する

#### 操作仕様

| 操作              | 動作              |
| --------------- | --------------- |
| ダブルクリック（通常）     | クリック地点を中心にズームイン |
| ダブルクリック（全体表示状態） | 全体表示へズームアウト     |

#### 詳細仕様

* ダブルクリック時のマウス位置をズーム中心とする
* ズームイン／ズームアウトは**アニメーション付き**で段階的に行う

  * ScaleTransform に対する DoubleAnimation を使用
  * アニメーション時間：例 200～300ms
* 「全体表示」とは以下を満たす状態を指す

  * キャンバス全体がビューポート内に収まるズーム率
  * ScrollViewer のスクロール位置は左上基準でリセット

---

### 4.5 ズームスライダー連動

#### 概要

* 画面外部に配置した Slider によりズーム率を直接操作できる

#### 操作仕様

| 操作      | 動作     |
| ------- | ------ |
| スライダー操作 | ズーム率変更 |

#### 詳細仕様

* スライダーの値とキャンバスのズーム率は**双方向バインディング**される
* スライダー値の単位はパーセント表記（例：10～400）
* 以下の操作とスライダーは常に同期する

  * Ctrl + MouseWheel
  * ダブルクリックズーム
* スライダー操作時も、ズームの中心は**現在のビューポート中央**とする

---

### 4.6 図形の選択・複数選択

#### 概要

* キャンバス上に配置された図形を選択・複数選択できる

#### 操作仕様

| 操作           | 動作             |
| ------------ | -------------- |
| 左クリック        | 単一図形選択         |
| Ctrl + 左クリック | 複数選択の追加／解除     |
| ドラッグ（空白領域）   | 範囲選択（ラバーバンド選択） |
| キャンバス空白クリック  | 選択解除           |

#### 詳細仕様

* 選択状態の図形は、以下のいずれかで視覚的に判別可能とする

  * 枠線の強調表示
  * 選択用アドーナー（Adorner）表示
* 複数選択時は、選択対象をコレクションとして管理する
* 選択状態は ViewModel 上で管理し、UI とはデータバインディングで連携する
* 図形選択中は、パン操作（左ドラッグ）と競合しないよう、以下の制御を行う

  * 図形上ドラッグ：図形移動
  * 空白領域ドラッグ（左）：範囲選択
  * 空白領域ドラッグ（右）：パン操作

---

### 4.7 Undo / Redo 機能

#### 概要

* ユーザー操作を履歴として管理し、操作の取り消し（Undo）およびやり直し（Redo）を可能とする

#### 操作仕様

| 操作       | 動作   |
| -------- | ---- |
| Ctrl + Z | Undo |
| Ctrl + Y | Redo |

#### 対象操作

* 以下の操作を Undo / Redo の対象とする

  * 図形の追加
  * 図形の削除
  * 図形の移動
  * 図形のサイズ変更
  * 図形の選択状態変更（複数選択含む）
  * ズーム率変更（※任意、設定で有効／無効切替可能）

#### 詳細仕様

* Undo / Redo はコマンド履歴方式で実装する

  * 各操作を ICommand 相当の履歴オブジェクトとして記録
  * Execute / Undo を明示的に定義
* Undo スタック、Redo スタックは以下の制約を持つ

  * 最大履歴数：例 100 操作（超過時は古い履歴を破棄）
* 新規操作が発生した場合、Redo スタックはクリアされる
* Undo / Redo 実行時は UI を即座に同期更新する

---

## 5. 非機能要件

### 5.1 操作性

* ズーム・パン操作は遅延なくスムーズに反応すること
* 高頻度な MouseWheel 操作でも UI がフリーズしないこと

### 5.2 拡張性

* 将来的に以下の機能追加を想定しても、ズーム・パン機構を流用可能な設計とする

  * 図形選択／移動
  * 図形の接続線表示
  * ミニマップ表示

### 5.3 保守性

* ズーム率・スクロール補正ロジックは専用クラスまたは ViewModel に分離する
* UIイベント処理は最小限に留め、ロジックをコードビハインドに集中させない

---

## 6. 制約事項

* .NET Core / .NET 6 以降は使用しない
* 外部UIコントロールライブラリ（例：DevExpress, Infragistics 等）は使用しない
* **MVVM・データバインディング関連のライブラリとして以下を必須とする**
  * [Fody.PropertyChanged](https://github.com/Fody/PropertyChanged): ViewModelのプロパティ変更通知自動化のため
  * [ReactiveProperty](https://github.com/runceel/ReactiveProperty): リアクティブなプロパティ・コマンド定義のため
* 上記以外は原則としてWPF標準機能のみで実装する
